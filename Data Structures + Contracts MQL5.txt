{

11. Hal penting: jangan membuat SRCluster memiliki terlalu banyak tanggung jawab

Kita sengaja tidak menyimpan seluruh SRLevel[] di dalam SRCluster.

Jangan membuat seperti:

struct SRCluster
{
   SRLevel Levels[100];
};

untuk versi awal.

Lebih baik:

SRLevel[]
    +
cluster assignment
    ↓
SRCluster[]

Ini membuat engine lebih sederhana dan lebih mudah di-debug.

13. Pip conversion

Karena strategi kita menggunakan pips, kita jangan mencampurnya langsung dengan _Point.

Buat helper:

double PipSize(string symbol)
{
   int digits = (int)SymbolInfoInteger(
      symbol,
      SYMBOL_DIGITS
   );

   double point = SymbolInfoDouble(
      symbol,
      SYMBOL_POINT
   );

   if(digits == 3 || digits == 5)
      return point * 10.0;

   return point;
}

Lalu:

double PipsToPrice(
   string symbol,
   double pips
)
{
   return pips * PipSize(symbol);
}

dan:

double PriceToPips(
   string symbol,
   double priceDistance
)
{
   return priceDistance / PipSize(symbol);
}

Dengan ini:

5 pips

tidak salah diterjemahkan menjadi:

5 points

pada EURUSD/GBPUSD 5-digit.

14. Kontrak waktu GMT

Jangan biarkan engine lain memproses jam sendiri-sendiri.

Buat satu helper:

bool IsEntryWindow(
   datetime gmtTime,
   SRStrategyConfig &cfg
)
{
   MqlDateTime t;
   TimeToStruct(gmtTime, t);

   int currentMinutes =
      t.hour * 60 + t.min;

   int startMinutes =
      cfg.EntryStartHourGMT * 60 +
      cfg.EntryStartMinuteGMT;

   int endMinutes =
      cfg.EntryEndHourGMT * 60 +
      cfg.EntryEndMinuteGMT;

   return (
      currentMinutes >= startMinutes &&
      currentMinutes < endMinutes
   );
}

Dengan begitu semua engine menggunakan definisi waktu yang sama.

15. Kontrak lifecycle

EA nantinya tidak melakukan semuanya setiap tick.

Konsep lifecycle:

TICK
 │
 ├── New D1?
 │      └── Rebuild D1 levels
 │
 ├── New H4?
 │      └── Rebuild H4 swings
 │
 ├── New M15?
 │      ├── Update touches
 │      ├── Update invalidation
 │      ├── Check rejection
 │      └── Evaluate trade
 │
 └── Every tick
        ├── spread
        ├── open position management
        └── force close

Ini penting agar EA tidak melakukan perhitungan berat berulang kali pada setiap tick.

#include "include/SRConstants.mqh"

SRRiskState  g_risk;

Lifecycle:

int OnInit()
{
   g_strategy = DefaultStrategyConfig();

   if(_Symbol == "EURUSD")
      g_symbol = DefaultEURUSDConfig();

   else if(_Symbol == "GBPUSD")
      g_symbol = DefaultGBPUSDConfig();

   else
      return INIT_PARAMETERS_INCORRECT;

   return INIT_SUCCEEDED;
}

Untuk sementara kita sengaja hanya mengizinkan EURUSD dan GBPUSD.

Pair lain baru ditambahkan setelah framework terbukti bekerja.
